# BankManager

Консольное приложение для управления банковскими счетами.

## Возможности
- Добавление клиентов
- Открытие дебетовых и кредитных счетов
- Пополнение, снятие, перевод
- История транзакций
- Сохранение и загрузка данных

## Стек
- C++17
- STL (vector, map, algorithm)
